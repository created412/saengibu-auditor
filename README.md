# 생기부 감사관

> 학교생활기록부 기재요령에 맞춰 세특을 점검하고, 선생님이 확인한 사실만으로 고칩니다.

작성된 교과 세특을 **진단 → 처방 → 수정**까지 끝내는 교사용 도구입니다.
세특을 대신 써 주는 AI가 아니라, **부족한 정보를 교사에게 정확히 물어보고 그 답으로 기록을 복구**합니다.
원칙은 둘 — **API 키 없이 동작**, **AI 임의 사실 추가 0건.**

## 실행

설치·빌드·API 키 없음. `index.html`을 브라우저로 열면 됩니다. 인터넷이 없어도 모든 기능이 동작합니다(웹 글꼴만 기본 글꼴로 보이고, 엑셀 파일은 CSV로 올리면 됨).

```bash
node --test tests/engine.test.js   # 엔진 테스트
```

모든 지적에는 근거 조항이 붙습니다(예: `기재요령 18쪽 3-나 · 118쪽 바-2`). 쪽수는 「2026학년도 학교생활기록부 기재요령(고등학교)」 인쇄 쪽 번호입니다.
상호명·기관명·학교명은 상위 일반어로 바꾸는 처방(챗GPT → 인공지능 챗봇, 구글 → 포털사이트 …)을, 나머지 금지 사항은 해당 절 삭제를 제안합니다.
교과서 속 고유명사(독립 협회, 이순신 동상 등), 도서명(『 』), 교육관련기관(교육청 등)은 오탐하지 않도록 맥락 조건을 둡니다. 그래도 잘못 잡으면 ‘금지 사항 아님(교사 확인)’으로 해제합니다.

## 기능

**개별 감사** — 수정본을 그냥 주지 않습니다. **감사 대상 기록 자체가 수정 작업대**입니다.

- 기록에 **형광펜**을 칠합니다 — 빨강은 위험(기재 금지), 노랑은 주의(수정 권장).
- 형광펜을 클릭하면 그 자리에 **왜 문제인지 · 근거 조항(쪽수) · 처방**이 열립니다(좁은 화면에서는 아래쪽 시트).
- 특정 구절이 아니라 **글 전반에 걸린 지적**(활동 나열 · 성장 흐름 없음 · 분량 초과)은 기록 위 **‘글 전반 지적’ 단서**로 띄우고, 근거가 된 범위에 **엷은 점선 밑줄**을 그립니다. 단서나 밑줄을 클릭하면 같은 풍선에서 처방까지 이어집니다.
- **여러 사례 이어 감사**: `‹ 이전 / 다음 › / + 새 사례`. 사례마다 수정본·확인한 사실·판정이 따로 보존되고, 학급 감사의 ‘자세히’로 열면 새 사례로 추가됩니다.
- 처방은 **3초 처방** — 자료에서 근거 찾기 · 내가 관찰한 내용 추가 · 문제 표현 삭제 · 대체어로 바꾸기. 고른 처방의 결과를 미리 보고 적용하면 바로 다시 감사합니다.
- 함께 보여 주는 것: 7대 감사기준 점수, 이름 바꿔도 되는 세특인가(학생 교체 가능성), 증거 연결 분석(교사 평가 ← 학생 사고 ← 학생 행동), 원자료 대조, 나이스 바이트, 수정 전·후 비교, 되돌리기, 직접 편집, 교사 확인 사실 / 개선 문장 / AI 임의 추가 집계.

**학급 감사 · 세특 응급실** — 엑셀 복사 붙여넣기·CSV·엑셀, 생기부 건강도, 위험·주의·양호 분류, 기재 금지 유형 집계, 🧬 세특 DNA(같은 문장 뼈대를 쓴 학생 묶음·유사도), 가장 많이 쓴 표현, **집중치료**(위험 학생 먼저 · 기재 금지는 반드시 처리 · 주의는 학생당 최대 3문항), 완료 보고서, 결과 CSV, 학기 초 관찰 포인트.

## 설계 원칙

| 원칙 | 구현 |
|---|---|
| 점수가 흔들리면 신뢰가 무너진다 | 규칙 엔진(`js/engine.js`, `js/lexicon.js`)이 계산. 같은 기록 = 같은 점수 |
| 기재 금지는 점수로 상쇄되지 않는다 | 위험은 품질 점수와 분리해 입력 가능 여부로 판정 |
| AI가 사실을 지어내면 안 된다 | 관찰 후보는 〔 〕 칸을 교사가 실제 관찰 내용으로 채워야 적용됨(반 전체 획일화도 방지). 사실 가드가 수정본의 새 어절·바뀐 수치·뒤집힌 부정 표현을 원문·교사 확인 사실과 대조 |
| 검토 상태 ≠ 문장 품질 | 주의 항목을 ‘유지’하면 목록에서 빠지지만 점수는 오르지 않음 |
| 결과는 초안 | 기재요령 19쪽 5-다: AI 보조 시 최종 입력 전 교사 확인 필수 |

## 파일

```
index.html          화면 골격
css/app.css         스타일(기재요령 표지 오마주: 아치·알약 배지·모서리 태그, 반응형·인쇄)
js/korean.js        명사형 종결·연결형·활용 변환, 조사, 문장 분리(소수점 보호), 나이스 바이트
js/lexicon.js       감사 사전 — 위험 규칙(조항·쪽수), 상호명 대체어, 주의 사전, 관찰 후보 (학교 사정에 맞게 수정)
js/engine.js        감사·처방·수정·사실 가드·학급 분석
js/art.js           표지 오마주 선화 일러스트(SVG)
js/demo.js          시연용 가상 데이터(이름·기록 모두 가상)
js/app.js           화면 로직
tests/              엔진 테스트
```

기재 금지 목록은 2026학년도 기재요령 기준입니다. 학년도가 바뀌면 `js/lexicon.js`의 `DANGER_RULES`와 쪽수를 갱신하세요.
화면은 기재요령 표지를 오마주했으며, 교육부·시도교육청·KERIS의 로고나 명의는 사용하지 않습니다. 이 도구는 공식 기관의 제작물이 아닙니다.
